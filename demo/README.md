# デモ動画の録画

スマホの大きさ（390x844）の画面を、GPS を動かしながら録画する。動画は `demo/recordings/<シーン>.webm`（git には入れない）。
同時に「期待した画面の状態になったか」を表示するので、簡易の end-to-end チェックにもなる（なっていなければ終了コード 1）。

## 使い方

```
npm run dev                                   # 別の窓で先に起動しておく
npm run record:demo -- train                  # 1 シーンだけ
npm run record:demo -- all                    # 全部（順に）
npm run record:demo -- plan --base http://localhost:3000 --headed   # 画面を見ながら
```

- ブラウザはダウンロードせず、入っている Edge（なければ Chrome）を使う。
- 録画に要る ffmpeg は、PC に入っているものを `demo/.pw/` に写して使う（ダウンロードしない）。
- AI を使うシーン（train / after / plan）は、実際の API を呼ぶので数円かかる。

## シーン

| シーン | 映るもの | 確かめる状態 |
|---|---|---|
| `train` | 京阪本線 七条〜祇園四条を北へ時速50km（約40秒）。丹波橋→出町柳の計画を入れてある | 「電車で移動中と推定しました」、次の駅（推定）が祇園四条、AI の見直しが届く |
| `train-shinjuku` | 京都から初めて新宿へ：JR 中央線快速で代々木〜新宿を北へ時速45km（約40秒）。京都→東京→新宿の計画を入れてある | 「電車で移動中と推定しました」、次の駅（推定）が新宿、AI の見直しが届く |
| `shinjuku-enter` | 新宿駅の範囲の少し南から時速5kmで歩いて入る → 駅の中の地図を開く → B1 → 2F | 「新宿駅の範囲に入りました」、地図が出る、階ボタン B1・2F |
| `route3d` | 新宿駅で一番近いトイレのカードから駅の中の道順を開く → いまどこ？ 改札の近く・西口地上改札（`ROUTE_START=car7` なら大江戸線のホーム・7号車）→ 最初の向き（作り物のコンパスを回して合わせる）→ 上から見る画面で「▶ 歩く」→ 押す階が出たら歩く目線に切り替えて、エレベーターに乗ってトイレまで | 道順が出る、「この向きでOK」、押す階、「トイレに着きました」 |
| `after` | 新宿駅で「トイレに入った」→「下着を汚した」→ AI の手順をゆっくりスクロール | 「AI が作った手順」が出る（簡易版になったら NG） |
| `plan` | 京都→新宿の経路を貼り、「今日は調子が悪い」「替えを持っていない」で計画を作る | 「経路と車内の設備」が出る（最大90秒待つ） |

## メモ

- `shinjuku-enter` の歩く距離は、範囲の手前 120m が既定（300m だと約3分半かかる）。`OUTSIDE_M=300` で変えられる。
- AI の見直しは、アプリの側で「約300m 動いたとき・1分に1回まで」に絞ってある。回数制限（10分に8回）に当たったら、開発サーバーを起動し直すか10分待つ。
- 画面の左下に Next.js の開発用バッジ（N）が映る。消したいなら `npm run build && npx next start` の本番サーバーに `--base` を向ける。
- タップした場所には、動画で分かるように薄い丸を出している。
