## メモ
- 声は約730字。1秒に5字ほどのゆっくりした読みで約2分25秒。録ってから、場面の長さを声に合わせて直す（下見の動画は場面ごとの長さを `make_cool.py` の SEGS で変えられる）。
- ③ の画面録画は短い（約6秒）。声に合わせて、画面を止めずに少し遅くするか、カードの下までゆっくり見せる。
- ⑤ は麻布十番に店のデータがないので、画面では「着替えられる多機能トイレ」が中心になる。声は「替えを買える店」も言うので、店のデータのある駅（新宿）の画面を一瞬はさむか、声から外す。
- ② の画面に「Yahoo!乗換案内を開く」のリンクが映る。会社名を出さないなら、録るときに隠す。
- 症状の言い方は「クローン病の人のなかには」（病気全体の説明にしない）。病名は冒頭の2文だけで、あとは繰り返さない。
- ⑤ の言い方は「もし下着が汚れてしまっても」（「間に合わなかった」は失敗と受け取られやすいので使わない）。本人に確かめる。
- 言い過ぎないこと：時刻からの推定は「ずれることもある」、道順は「データの上で」いちばん早く、電波なしは「一度開いておけば」。
