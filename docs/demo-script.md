## メモ
- 読み上げに渡すときは、英字をかなに（Claude→クロード、GPS→ジーピーエス、3D→スリーディー、AI→エーアイ）、数の読みを指定し（1回生→いっかいせい、地下6階→ちかろっかい など）、かぎかっこは外す（間が空きすぎるため）。
- 画面録画は本番サーバー（`npx next start`）に向けて撮る（開発用のバッジが映らない）。
- 3分以内に収めるため、駅の中の長い歩きは早送りにし、画面の右上に「▶▶ 3.1倍速」などを出す。
- 無言の時間を作らない：場面の長さは声に合わせる（画面録画が長いときは、2.5倍まで速めて詰める）。
- 「開けば」は「ひらけば」と読ませる（そのままだと「あけば」と読まれる）。
- 音量は loudnorm でそろえる（固定で上げると音割れする）。
- 症状の言い方は「クローン病の人のなかには」（病気全体の説明にしない）。病名は冒頭だけで、あとは繰り返さない。
- 「大丈夫です」は言わない（アプリでも AI に言わせていない、気休めの言葉）。
- 会社名（乗換アプリの名前）は出さない。乗換アプリの画面は実在のアプリに似せない小道具で、画面と声の両方で「外部のアプリのイメージ」と言う。
