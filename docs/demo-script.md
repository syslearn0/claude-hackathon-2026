## メモ
- 合成音声には、読みを助けるため「Claude」を「クロード」、「GPS」を「ジーピーエス」と書いて渡す。
- 画面録画は本番サーバー（`npx next start`）に向けて撮る（開発用のバッジが映らない）。
- 3分以内に収めるため、駅の中の長い歩きは早送りにし、画面の右上に「▶▶ 2倍速」などを出す。
- 症状の言い方は「クローン病の人のなかには」（病気全体の説明にしない）。病名は冒頭だけで、あとは繰り返さない。
- 会社名（乗換アプリの名前）は出さない。
