# 計画（2026-11-02 キックオフ時点）

## 作品の形
急なトイレの不安がある人の外出を、**確かめた事実の情報**で支える Web アプリ（スマホのブラウザで使う）。
作者自身がクローン病の当事者。当事者への聞き取りで分かった困りごとを起点にする。

| 場面 | すること | AI |
|---|---|---|
| ① 出かける前（「今日は調子が悪い」日） | 行き先の周りで使える場所（改札内トイレと号車、着替えられる多機能トイレ、替えを買える店、座れる場所）と持ち物をまとめた計画 | 使う |
| ② 急に来たとき | 押すだけ。プログラムが即座に近いトイレとお願いカードを出す。並行して AI が GPS・時刻表・運行情報・今日の計画から状況を判断し直し、③の準備を始める | 並行して使う |
| ③ トイレに入った後 | 替えを売っている開いている店（売り場の場所つき）、着替えられる場所、帰るか続けるかの選択肢 | 使う |

### 勝負する情報（地図アプリにないもの）
改札の内か外か／ホームの何号車から近いか／所要分／着替えられるか／替えを売る店と売り場／男性個室のサニタリーボックス／座れる場所

### データの3段
1. 全国：OpenStreetMap（トイレ・コンビニ・ドラッグストア・営業時間）
2. 公式データのある地域：東京都・区のトイレ CSV、ODPT（駅・時刻表・運行情報）
3. 現地確認済み：東京は協力者、京都は作者（京阪 丹波橋〜出町柳）

### 11/2 に分かったこと（データの有無）
- ODPT の駅施設情報（改札内外・号車ごとの設備）は、公開 API では 404。データカタログにも見当たらない。登録後の API で取れるかは未確認
  → **「改札内外・号車」は現地確認で作る独自データが主役**になる
- 都営の運行情報は登録なしで取れる（文章のみ。原因・再開見込みの別項目はない）。東京メトロは登録すれば取れる
- JR東日本の駅・運行情報、京都市営地下鉄の GTFS は ODPT チャレンジ限定
- 京阪はオープンデータなし。公式 PDF（時刻表・構内図・乗車位置案内）に改札内外や号車ごとのトイレがあるが、サイトの規約で無断の公開・営利利用は禁止
  → 京阪の区間は**自分で見て確かめた情報**として持つ。PDF の中身を写して公開しない

画面には、情報がどの段から来たか（と確認日）を必ず出す。

## 線引き
- 症状・受診・食事の判断はしない。選択肢と事実を並べるだけ
- 道具の結果にないトイレ・店は出さない（根拠チェックをプログラムで行う）
- 病名は入力にも画面にも出さない
- 位置情報は判断に必要な最小限だけ送り、保存しない
- 面談の記録そのもの・生の GPS 記録はこのリポジトリに置かない

## 状況判断の分担
- プログラム：GPS と線路の照合、速度、時刻表との照合 → 仮説と確からしさ
- AI：食い違う材料の判断、運行情報など文章の読み取り、利用者の条件との組み合わせ
- 画面のルール：0秒の表示を黙って差し替えない。大きく違うときだけ理由つきで出す
